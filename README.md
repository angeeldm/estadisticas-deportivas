# estadisticas-deportivas

## Integrantes
Angel Mejia

## Escenario
Estadísticas de Resultados Deportivos

## Descripción del Proyecto
Este proyecto tiene como objetivo analizar datos de resultados deportivos correspondientes al campeonato local de la English Premier League 2025-2026, utilizando herramientas de análisis de datos. A partir de un dataset de partidos, se procesan los resultados para obtener:
- Cantidad de partidos ganados por cada equipo
- tabla de posiciones
- promedio de goles por partido

## Dataset
El dataset se obtuvo de la URL https://datahub.io/football/english-premier-league
Los datos relevantes usados para el proyecto son:
HomeTeam	AwayTeam	FTHG	FTAG	FTR
